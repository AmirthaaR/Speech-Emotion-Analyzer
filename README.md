# Speech-Emotion-Analyzer

# Dataset

This project uses the RAVDESS (Ryerson Audio-Visual Database of Emotional Speech and Song) dataset.

Dataset source:

https://zenodo.org/records/1188976

The dataset contains speech recordings representing eight emotions:

- Neutral
- Calm
- Happy
- Sad
- Angry
- Fearful
- Disgust
- Surprised

Please download the Audio Speech Actors 01-24 dataset and place it in:

data/RAVDESS/Audio_Speech_Actors_01-24/

The dataset is not included in this repository because of its large file size.

After downloading the dataset, run the preprocessing scripts to generate the required features.
